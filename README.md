# U.S. BEA GDP Tools

U.S. BEA GDP Tools is a free, open-source project for retrieving gross domestic
product (GDP) and population data from the U.S. Bureau of Economic Analysis
(BEA). It supports national, state, and metropolitan analysis. For
Metropolitan Statistical Areas (MSAs) and Combined Statistical Areas (CSAs),
the project retrieves county-level records, aggregates them using current OMB
delineations, and retains the underlying county detail in Excel exports.

The project focuses on current-dollar GDP, real GDP in chained dollars, and
population. Data is requested through the BEA API, so available periods update
with BEA's official releases.

## Why this project exists

In 2025, BEA announced that it would stop publishing GDP and personal income
estimates for county-aggregate geographies, including MSAs and CSAs. Rebuilding
metro estimates manually requires retrieving and combining many county records.
This project automates the batching, aggregation, validation, and workbook
export process.

> Metropolitan results generated by this project are user-created estimates
> based on BEA county data. They are not official metropolitan estimates
> published by BEA.

MSA and CSA membership follows
[OMB Bulletin 23-01](https://www.whitehouse.gov/wp-content/uploads/2023/07/OMB-Bulletin-23-01.pdf),
issued in July 2023. See
[BEA's metropolitan-data explanation](https://www.bea.gov/help/faq/1481) for
additional context.

## Metro Studio

Metro Studio is the application distributed by the U.S. BEA GDP Tools project.
It is available as a responsive website, a Windows x64 desktop application, and
an Android application.

## Downloads

Download packaged applications from the
[GitHub Releases page](https://github.com/BillydavisUSA/U.S.-BEA-GDP-Tools/releases):

- `Metro-Studio-Setup-1.0.0-x64.exe` — Windows x64 installer.
- `Metro-Studio-Portable-1.0.0-x64.exe` — portable Windows x64 application.
- `Metro-Studio-1.0.0-Android-x86_64.apk` — Android x86_64 application for
  Android 12 or later.

Release binaries are intentionally excluded from the source repository. Upload
the three files above as assets attached to a GitHub Release, not as files in
the repository. SHA-256 checksums are provided in `release/SHA256SUMS.txt`.

## Run from source

Install [Node.js 22 or later](https://nodejs.org/), clone the repository, and
install the locked dependencies:

```bash
git clone https://github.com/BillydavisUSA/U.S.-BEA-GDP-Tools.git
cd U.S.-BEA-GDP-Tools
npm ci
```

Run the responsive website:

```bash
npm run dev:web
```

Run the Windows desktop application:

```bash
npm run desktop
```

## Windows 64-bit desktop

Build the Windows x64 installer:

```bash
npm run desktop:pack
```

The installer is written to
`release/Metro-Studio-Setup-1.0.0-x64.exe`. To build only the unpacked
application directory:

```bash
npm run desktop:dir
```

Build a single-file portable executable that runs without installation:

```bash
npm run desktop:portable
```

The output is written to
`release/Metro-Studio-Portable-1.0.0-x64.exe`.

The desktop application requests the BEA API through an isolated Electron main
process. The renderer has no Node.js access, and external reference links open
in the system browser.

## Android 12–17 x86_64

The Android shell uses Capacitor, requires API 31 or newer, targets API 36, and
is forward-compatible with Android 17 (API 37). It uses the native BEA HTTP
bridge and saves Excel workbooks through the Android share sheet.

Install Android Studio with Android SDK Platform 36. The build script detects
Android Studio's bundled JDK and the default SDK location automatically. Custom
installations can set `JAVA_HOME` and either `ANDROID_HOME` or
`ANDROID_SDK_ROOT`. Run:

```bash
npm run android:build:x64
```

The installable debug APK is copied to
`release/Metro-Studio-1.0.0-Android-x86_64.apk`.

## Web development

The public website has its own responsive entry and does not reuse the Windows
or Android application shell:

```bash
npm run dev:web
npm run build:web
npm run test:web-layout
npm run test
```

Netlify publishes `dist-web/`. The desktop and Android applications continue
to use the separate `dist/` build:

```bash
npm run dev
npm run build
npm run test:visual
```

If Windows PowerShell blocks `npm.ps1`, use `npm.cmd` instead.

`node_modules/`, `dist/`, `dist-web/`, Android build caches, and release binaries are
reproducible outputs and are not committed to the source repository. Publish
the files stored in `release/` as GitHub Release assets.

When uploading the repository, use Git (`git add`, `git commit`, and
`git push`) so `.gitignore` is respected. Do not drag the entire local project
folder into GitHub's browser uploader, because the local folder may contain
ignored dependencies, caches, and release binaries.

The website and installed applications link to the
[U.S. BEA GDP Tools repository](https://github.com/BillydavisUSA/U.S.-BEA-GDP-Tools).
To use a different repository in a custom build, copy `.env.example` to `.env`,
change `VITE_GITHUB_URL`, and rebuild.

## Data sources, privacy, and license

- Data is provided by the U.S. Bureau of Economic Analysis (BEA).
- Metropolitan boundaries are reconstructed from the latest OMB bulletin.
- The application does not modify official BEA statistics. It aggregates

## Data rules

- Requests always use `METHOD=GETDATA` and `RESULTFORMAT=JSON`.
- `Metropolitan Statistical Area` rows map to MSAs. Micropolitan areas are not
  included.
- Records with the same `CSA Title` are combined into a CSA.
- `FIPS State Code` and `FIPS County Code` are zero-padded and concatenated
  into complete five-digit `GeoFips` codes.
- Search supports MSA, CSA, and combined filters.
- Selecting all metro areas deduplicates GeoFips codes, loads them in batches,
  and aggregates each MSA/CSA independently.
- `TimePeriod` maps to year.
- Supported measures are `CAGDP1` gross domestic product (`LINECODE=1/3`,
  thousands of dollars) and `CAINC1` population (`LINECODE=2`, persons).
- `DataValue` records are summed by metro area and year for the selected
  measure.
- With `CAINC1` and `YEAR=ALL`, only records from 2001 onward are included in
  aggregation, preview, and export.
- County records with `DataValue=0` are excluded. Every nonzero value is
  included even when it has a `NoteRef`. A metro-area year is reported as
  `No data` only when every county value is zero. An unparseable `DataValue`
  also marks that year as `No data`.
- Current BEA Regional requests exclude Puerto Rico `72xxx` GeoFips codes.
  Affected metro areas remain visible in search and export with `No data`.
- Excel uses metro areas as rows and years as columns. MSA and CSA results use
  separate `Metropolitan Statistical Area` and `Combined Statistical Area`
  worksheets. The `Metro Area County Data` worksheet always preserves
  county-level `DataValue`, `NoteRef`, and aggregation status.
- Each workbook also includes a `Request Parameters` worksheet.

## Updating metro-area data

Replace `data/list1_2023.xlsx`, then run:

```bash
npm run build:data
```

This regenerates `src/data/metro-areas.json`.
