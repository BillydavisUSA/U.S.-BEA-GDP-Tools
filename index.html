Data statement

Data provided by the U.S. Bureau of Economic Analysis (BEA).

Metropolitan boundaries reconstructed from the latest OMB Bulletin.

This application preserves reported BEA values; only MSA/CSA aggregation and the optional national quarterly cumulative view are calculated in the application.

Initial Windows x64 release

  • Explore national data, 51 state geographies, 393 MSAs, and 184 CSAs.
  • Query current-dollar GDP, real GDP in chained dollars, and population across official BEA periods.
  • Aggregate eligible county records using OMB Bulletin 23-01 metro delineations while preserving county DataValue and NoteRef details.
  • Load annual or quarterly national GDP, calculate optional quarterly cumulative values, and export multi-sheet Excel workbooks.
  • Send BEA requests through an isolated Electron process and save Excel files locally, with light, dark, and reduced-motion support.

Minimal network use
The app connects only to apps.bea.gov when you run a query.

What the app processes

Metro-area selections, years, measures, GeoFips codes, BEA responses, and generated workbooks. They are used only for the current task and are never sent to the app developer.

Retention

The app does not operate a server database or retain query history. In-memory results are discarded when the application closes.
