# Metro Studio Privacy Policy

Effective date: July 24, 2026

Metro Studio is designed to work without collecting personal information.
You do not need an account and you are not asked to provide a name, email
address, phone number, payment information, precise location, or any other
identity information.

## Information we collect

Metro Studio does not collect or transmit personal information to the
application developer. The application contains no advertising, analytics SDK,
behavioral tracking, marketing cookies, crash-reporting service, or telemetry.

## Data processed on your device

To perform the task you request, the application processes:

- your selected metropolitan area, year, table, and metric;
- county GeoFips values used for aggregation;
- BEA JSON files you choose to import; and
- spreadsheets you choose to export.

Imported JSON is read locally. Query results remain in application memory for
the current session. Exported Excel files are written only to a location you
choose through the operating system. The application does not maintain a
server-side database or a cloud query history.

## Network requests

When you request online data, the application sends only the parameters needed
to complete that request to the U.S. Bureau of Economic Analysis at
`apps.bea.gov`. Like any internet service, BEA may receive standard network
information such as an IP address, request time, and user agent under its own
policies. Metro Studio does not receive a copy of BEA's server logs.

When you open an external documentation link, your default browser connects to
the linked BEA, U.S. Census Bureau, Apache Software Foundation, or future GitHub
page. Those sites apply their own privacy policies.

## Data retention and sharing

The application developer does not receive, retain, sell, rent, or share your
query selections, imported files, exported files, or personal information.
Closing the application ends the in-memory session.

## Changes

If a future version introduces any optional feature that changes these
practices, this policy and the in-application Privacy page will be updated
before that feature is released.
