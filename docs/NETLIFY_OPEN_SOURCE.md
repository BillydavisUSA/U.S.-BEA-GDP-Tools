Netlify has approved or sponsored the project. No application has been submitted
by this change.

## Project material

- Project: **U.S. BEA GDP Tools (Metro Studio)**.
- Repository: <https://github.com/BillydavisUSA/U.S.-BEA-GDP-Tools>.
- License: [Apache License 2.0](../LICENSE).
- Conduct: [Code of Conduct](../CODE_OF_CONDUCT.md).
- Collaboration: [Contributing](../CONTRIBUTING.md).
- Website: **the maintainer must supply the actual deployed URL**.

Suggested project description:

> U.S. BEA GDP Tools is a free, Apache-2.0-licensed website that helps users
> query U.S. GDP and population data, reconstruct county-based metropolitan,
> city, and bay-area estimates, and export auditable Excel workbooks. It also
> supports state and national data. English and Chinese interfaces and
> geographic display names make the data more accessible. The public GitHub
> repository welcomes code, translation, documentation, and data-correction
> contributions. The website directly serves users and contributors of this
> open-source project.

## Before submitting

The [official policy](https://www.netlify.com/legal/open-source-policy/) requires
an eligible open-source license, a prominently linked Code of Conduct, a link
back to Netlify on the main page or all internal pages, and a non-commercial
project. Commercial support and hosting services are included in that last
restriction. Final eligibility is decided by Netlify.

1. Publish the repository changes so reviewers can open the conduct and
   contribution links. Use their published `main` URLs in the application.
2. Deploy the revised website and confirm its footer displays
   **This site is powered by Netlify**, linked to <https://www.netlify.com/>.
3. Add the deployed website URL to GitHub's About field and the README.
4. The maintainer must confirm the project's actual non-commercial status,
   including whether any related support or hosting service is sold. Free
   source code alone does not establish eligibility; do not submit an
   unsupported declaration.
5. Provide the maintainer's own name and Netlify account email in the
   [official application form](https://opensource-form.netlify.com/), along
   with the repository, license, conduct, and website links. Do not commit
   private account information to this repository.

The [plan page](https://www.netlify.com/open-source/) and policy may change;
review them again when submitting. Approval, deployment, and any plan change
are separate from preparing these repository files.
