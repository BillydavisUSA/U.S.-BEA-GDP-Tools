# Release files

This directory holds the current Windows x64 installer, portable executable,
and Android x86_64 APK.

The binaries are intentionally ignored by Git. Upload them as assets on the
[project's GitHub Releases page](https://github.com/BillydavisUSA/U.S.-BEA-GDP-Tools/releases),
not to the source repository. `SHA256SUMS.txt` contains verification hashes for
all three files.
